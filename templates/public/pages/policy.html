{% trans "1. Présentation d'AutoLink" %}

{% trans "AutoLink est une plateforme numérique automobile mise en place au Cameroun, conçue pour connecter les automobilistes avec les professionnels de l'automobile : garages mécaniques, vendeurs de pièces détachées et prestataires de services automobiles." %}

{% trans "Notre mission est de simplifier l'entretien automobile en offrant un accès direct et transparent aux garages vérifiés, aux pièces compatibles et aux services de qualité, le tout à des prix clairs et négociables." %}

{% trans "AutoLink opère actuellement dans les principales villes du Cameroun, notamment Douala, Yaoundé, Bamenda, Bafoussam, Garoua, Maroua, Kribi et Bertoua, avec une extension continue à d'autres régions." %}

{% trans "2. Comment fonctionne AutoLink" %}

{% trans "AutoLink repose sur un écosystème simple et efficace qui profite à trois types d'utilisateurs :" %}

{% trans "Les automobilistes (clients)" %}

  • • {% trans "Rechercher des garages à proximité selon leur localisation" %}
  • • {% trans "Consulter les services proposés par chaque garage" %}
  • • {% trans "Commander des pièces automobiles compatibles avec leur véhicule" %}
  • • {% trans "Passer commande et payer de manière sécurisée (Mobile Money, carte, espèces)" %}
  • • {% trans "Laisser des avis et évaluations sur les garages et pièces" %}
  • • {% trans "Demander une assistance routière en cas de panne" %}
  • • {% trans "Signaler tout problème rencontré via le système de support intégré" %}

{% trans "Les garages professionnels" %}

  • • {% trans "Créer un profil professionnel vérifié par l'équipe AutoLink" %}
  • • {% trans "Publier leurs services et tarifs" %}
  • • {% trans "Mettre en vente des pièces automobiles avec photos et descriptions" %}
  • • {% trans "Gérer les commandes et le stock en temps réel" %}
  • • {% trans "Recevoir des avis clients pour asseoir leur réputation" %}
  • • {% trans "Gérer leur disponibilité en temps réel" %}

{% trans "L'administration AutoLink" %}

  • • {% trans "Vérifier l'identité et les qualifications des garages" %}
  • • {% trans "Assurer le support client et la résolution des litiges" %}
  • • {% trans "Garantir la sécurité des transactions" %}
  • • {% trans "Modérer les avis et les contenus publiés" %}

{% trans "3. Pourquoi nous avons besoin de votre position" %}

{% trans "AutoLink utilise les données de localisation de votre appareil uniquement pour vous offrir une meilleure expérience. Voici précisément pourquoi nous en avons besoin :" %}

📍 {% trans "Trouver les garages les plus proches" %}

{% trans "Lorsque vous recherchez un garage, votre position nous permet de vous afficher en priorité les établissements situés à proximité, classés par distance. Cela vous évite de parcourir inutilement des kilomètres pour un service disponible dans votre quartier." %}

🗺️ {% trans "Calculer les distances et itinéraires" %}

{% trans "Votre position nous permet de calculer la distance exacte entre vous et le garage sélectionné, et de vous fournir un itinéraire pour vous y rendre. Le calcul se fait en kilomètres en utilisant la formule de Haversine." %}

🔧 {% trans "Assistance routière en cas de panne" %}

{% trans "En cas de panne, votre position exacte est transmise au garage le plus proche afin qu'il puisse intervenir rapidement. Sans cette information, l'assistance routière ne pourrait pas fonctionner efficacement." %}

📦 {% trans "Livraison de pièces" %}

{% trans "Si vous commandez une pièce pour livraison, votre position permet d'estimer les frais de livraison et le délai estimé d'acheminement." %}

🔒 {% trans "Engagement de confidentialité" %}

  • • {% trans "Votre position n'est jamais partagée avec des tiers à des fins commerciales" %}
  • • {% trans "Les données de localisation sont utilisées uniquement pendant votre session active" %}
  • • {% trans "Vous pouvez révoquer l'accès à votre position à tout moment via les paramètres de votre appareil" %}
  • • {% trans "Nous ne stockons pas votre historique de localisation de manière permanente" %}
  • • {% trans "Aucune donnée de localisation n'est vendue ou partagée à des fins publicitaires" %}

{% trans "5. Règles applicables aux garages" %}

{% trans "Les garages souhaitant opérer sur AutoLink doivent respecter les règles suivantes :" %}

  • • {% trans "Fournir les documents de vérification nécessaires (registre de commerce, pièce d'identité, photo du local)" %}
  • • {% trans "Maintenir des informations exactes sur leurs services et tarifs" %}
  • • {% trans "Répondre aux demandes des clients dans des délais raisonnables" %}
  • • {% trans "Assurer la qualité des pièces vendues et des services rendus" %}
  • • {% trans "Respecter les statuts de disponibilité (Disponible, Occupé, Fermé)" %}
  • • {% trans "Gérer les commandes de manière professionnelle et dans les délais annoncés" %}
  • • {% trans "Ne pas publier de faux avis ou de contenus trompeurs" %}

{% trans "Tout garage ne respectant pas ces règles verra son profil suspendu ou supprimé après mise en demeure." %}

{% trans "6. Commandes et paiements" %}

{% trans "AutoLink facilite les transactions entre clients et garages tout en garantissant la sécurité :" %}

  • • {% trans "Les paiements sont sécurisés via Mobile Money (MTN MoMo, Orange Money) ou à la livraison" %}
  • • {% trans "Le code de retrait à 4 chiffres est généré automatiquement pour sécuriser le retrait en magasin" %}
  • • {% trans "Les annulations sont possibles tant que la commande n'a pas été confirmée par le garage" %}
  • • {% trans "En cas de litige, l'administration AutoLink intervient comme médiateur" %}
  • • {% trans "Les demandes de remboursement sont traitées sous 48 à 72 heures ouvrées" %}

{% trans "7. Pièces et compatibilité" %}

{% trans "AutoLink met l'accent sur la compatibilité des pièces pour éviter les achats inutiles :" %}

  • • {% trans "Chaque pièce est associée aux véhicules compatibles (marque, modèle, année)" %}
  • • {% trans "Les références OEM sont affichées pour faciliter la vérification" %}
  • • {% trans "L'état de la pièce (Neuf, Occasion, Reconditionné) est clairement indiqué" %}
  • • {% trans "Le stock et la disponibilité sont mis à jour en temps réel par le garage" %}
  • • {% trans "Les photos des pièces doivent être réelles et correspondre à l'objet vendu" %}

{% trans "AutoLink ne garantit pas la compatibilité lorsque le client sélectionne manuellement un véhicule non référencé dans la fiche produit." %}

{% trans "8. Avis et évaluations" %}

{% trans "Les avis jouent un rôle essentiel dans la confiance entre les utilisateurs. Les règles suivantes s'appliquent :" %}

  • • {% trans "Seuls les utilisateurs ayant interactué avec un garage ou une pièce peuvent laisser un avis" %}
  • • {% trans "Les avis doivent être honnêtes, pertinents et respectueux" %}
  • • {% trans "Les avis frauduleux, copiés ou fictifs seront supprimés" %}

  • • {% trans "Un score de confiance (trust score) est calculé automatiquement en fonction de la qualité du service" %}
